# Robyn Miller Instruments

The magic of physical modeling: a temporary page for Robyn Miller's synths and effects.

- `index.html` — the page: three playable instruments (clarinet → saxophone, piano, bass → violin), the words, the films
- `assets/` — the instruments: recordings and pictures of the real plug-ins at a row (or grid) of settings, plus the badge
- `media/` — the films and their posters
- `tools/build_assets.py` — renders `assets/` from the plug-ins' offline FilmShot harnesses

The page tells a parent page its height (`postMessage({ rmiHeight })`) so it can sit in a Squarespace Code block iframe.
